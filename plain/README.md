# 純記錄

全站的另一個版本：同一批內容，用統一、樸素的版面呈現，作者只用 GORILLA ONE 一個名字，方便和原版對照。

網址：https://monkeyzero-log.github.io/MONKEYZERO_LOG-BANANA/plain/

## 頁面

| 檔案 | 內容 | 資料從哪來 | 對照的原版 |
|:---|:---|:---|:---|
| `index.html` | 作者頁（也是首頁）：簡介、各頁入口、最近記錄、其他平台 | 繪畫、思考的數字自動算，其餘手寫 | 作者頁 |
| `drawing.html`、`drawing-set.html` | 繪畫：依分類列出系列，點進去看全部作品與心得 | 自動：`../drawing-log/data.js` | 作畫紀錄、習作輯 |
| `essays.html`、`essay.html` | 思考：文章列表與全文 | 自動：`../mind-journal/posts.js` 和 `pieces/` 裡的文章 | 思考錄（書櫃版、季刊版） |
| `writing.html` | 寫作：原創、同人、文字研究 | 手寫 | 文集 |
| `language.html` | 語言：學習日誌、方法實驗、自主研究 | 手寫 | 學語誌 |
| `tools.html` | 工具：專案說明與功能清單 | 手寫 | 工具間 |

## 平常要不要改這裡？

- **新增畫作、新增思考錄文章**：照原版的方法加就好（改 `drawing-log/data.js` 或 `mind-journal/posts.js`），這一版會自動出現，不用動這個資料夾。
- **寫作、語言、工具三頁**：原版這三區目前只有範例，沒有清單可讀，所以是手寫的。要加內容時，打開那一頁，最上面的註解有寫怎麼加。
- **作者頁的「寫作」「語言」「工具」統計**：這三格是手寫的，有新內容時記得到 `index.html` 一起改。

## 這一版刻意不放的東西

- 猴零士／猩其一的角色設定、角色口吻的說明文字、塗鴉、彩蛋（作者只寫 GORILLA ONE）
- 文章結尾的署名
- 原版裡只是佔位或範例的內容（例如透視課的示意圖、文集的範例篇、學語誌的填寫範本）
- 文字物理學（原版正在大改）、像素版作者頁、密碼保管箱

## 樣式

所有頁面共用 `style.css`，顏色和字體都在檔案最上面的 `:root`。
會跟著手機或電腦的深色模式自動切換。
